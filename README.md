📊 E-Commerce Sales & Profit Analysis Dashboard (Power BI)
An interactive 4-page Power BI dashboard designed to analyze e-commerce sales performance, profitability trends, customer segment distribution, and shipping efficiency.

📌 Project Overview
This project provides actionable insights for e-commerce business operations by tracking performance across key operational areas:

Executive Dashboard: High-level metrics including Sales, Profit, Orders, Return Rates, and Monthly Trends.
Product Performance Analysis: Sub-category breakdowns, Top 10 products by sales, and profit margin distributions.
Customer & Regional Insights: Revenue distribution across customer segments, states, and geographic regions.
Shipping & Payment Analysis: Delivery turnarounds, shipping modes, payment options, and return analysis.
🛠️ Tools & Technologies Used
Business Intelligence: Power BI Desktop
Data Transformation: Power Query
Data Modeling & Calculations: DAX (Data Analysis Expressions)
Visualizations: Custom Cards, Donut Charts, Clustered Bar/Column Charts, Matrix Tables
